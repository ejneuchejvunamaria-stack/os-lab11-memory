## Задание 1
Всего RAM 4,8Gi
Используется 2,4Gi
Свободно 195Mi
Доступно 2,2Gi
buff/cache 2,2Gi
Почему available (2,2Gi) существенно больше free (195Mi)?
Потому что в Linux свободная оперативная память активно используется под кэш (buff/cache). Когда программам потребуется память, ядро мгновенно освободит этот кэш. Поэтому available (доступно) показывает почти всю память, которую можно использовать, а free — это лишь та память, которая прямо сейчас вообще никак не задействована.
