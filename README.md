## Задание 1
Всего RAM 4,8Gi
Используется 2,4Gi
Свободно 195Mi
Доступно 2,2Gi
buff/cache 2,2Gi
Почему available (2,2Gi) существенно больше free (195Mi)?
Потому что в Linux свободная оперативная память активно используется под кэш (buff/cache). Когда программам потребуется память, ядро мгновенно освободит этот кэш. Поэтому available (доступно) показывает почти всю память, которую можно использовать, а free — это лишь та память, которая прямо сейчас вообще никак не задействована.

## Задание 3
`VmSize` и `VmRSS` различаются, потому что `VmSize` (виртуальный размер) показывает всё адресное пространство, выделенное процессу (включая зарезервированную, но еще не занятую физически память, а также разделяемые библиотеки). `VmRSS` (Resident Set Size) показывает только ту часть памяти, которая реально загружена в физическую оперативную память (RAM) прямо сейчас. В нашем случае VmSize = 11580 kB, а VmRSS = 4120 kB, так как не все виртуальные страницы в данный момент находятся в оперативной памяти.
